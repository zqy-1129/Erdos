# 负责人验收与冻结事项

数据侧目前可进入内部联调：19 个稳定赛事、各赛事 latex/docx 草稿 family、源文件清单/提取队列、题目与论文画像、版本快照、校验消费者、实际计算 demo。历史原件、旧 seed、阶段三与 Trae 原候选包均保留。

不得将“八阶段代码已提交”当作“十九赛事均达到可商用模板质量”。以下需要单独验收：

1. **真实内容覆盖**：空赛事只有格式和通用内容骨架；赛题/论文下载后还须建立内容身份关联。全库提取不等于全库论文已人工审核。
2. **画像质量**：已确认的页事实与自动候选分开；正文/摘要/目录/附录篇幅边界缺失、公式提取缺失、扫描页 OCR、旧 DOC 转换均进入队列。至少三篇金标准论文的完整结构、写法、篇幅和图型核对仍未完成，当前仅有页级事实核对。
3. **当届格式**：所有 ruleset_status=unknown。既有模板含历史年份与占位示例，仍要参数化当届年份/题号并核验官方格式，LaTeX 尚未编译。
4. **授权与发布**：当前历史论文未知授权；四维 false。谁可看原文、谁可用画像、是否可以发送 LLM 分别确认，带授权记录。不把 draft 的 tier=free 当作正式价格。
5. **跨端接入**：BE 审核新表/API/鉴权/对象键；FE 审核缓存、安全解包与状态；EN 审核 task 标签和求解/写作调用。真实产品端到端、OSS 和 LLM API 尚未验收。

当前包是独立完整快照，切换要事务化；旧快照可回滚。内容实体 ID 稳定、版本/hash 锁定，同版本冲突拒绝，唯一内容哈希可确认的改名保持 source_id。可能的多副本改名需要人工，不猜。

DE 可继续补数据而不等所有跨角色接口冻结；正式发布必须满足内容、规则、授权与产品联调各自验收。详细通过项、缺口和证据见最终独立验收报告，不沿用 Trae 原报告未经实证的“全通过”。
