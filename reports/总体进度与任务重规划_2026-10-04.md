### 3.2 解耦边界接口（跨端依赖只允许走契约）

| 边界 | 协议 | 契约文件 |
|---|---|---|
| 主进程 ↔ 引擎 | JSON-RPC 2.0（stdio/命名管道）+ NDJSON 事件流 | contracts/engine-rpc + IPC 契约三边一致性守护 |
| 渲染 ↔ 主进程 | contextBridge 白名单通道（contextIsolation，禁 Node 直连） | client preload 注册表 |
| 客户端 ↔ 云端 | REST /v1 + 统一信封 + Idempotency-Key | contracts/openapi.yaml |
| 权益许可/快照 | Ed25519 SPKI DER 验签 + 字节序规范 + 单调计数器 | contracts/snapshot.md |
| 遥测 | 事件名白名单 + 违禁字段剥离 + outbox 缓冲补报 | contracts/telemetry.schema.json |
| 内容分发 | manifest 增量 + oss_key+sha256（库不存文件内容） | 数据模型第 7 章 + 内容接口 |

硬约束回顾（强制遵守）：LangChain/LangGraph 仅限 engine/（CI 双门禁拦截）；模型流量 BYOK 直连不经平台；遥测不上报题面/Key/路径；资金域与密钥域变更 ARCH 双审；二进制字段只存 oss_key+sha256。

### 3.3 各域"不负责"边界（防重叠）

- **FE**：不动服务端表结构；不实现引擎业务逻辑；快照只管验签（签署在 BE）；支付只做拉起/轮询。
- **BE**：不生产内容数据（DE 灌库）；不部署监控（DE）；不做验收定性（QA）。
- **DE**：不改业务表字段；遥测摄入 API 由 BE 实现、DE 管管道；案例版权决策归项目负责人。
- **EN**：不直连云端业务 API；不读研发机 D:/Erdos_data；密钥经主进程一次性注入。
