## 二、全项目服务端集成矩阵

### 2.1 模块清单

| 模块 | 域 | 核心职责 |
|---|---|---|
| auth | 认证授权 | JWT 双令牌、RBAC、防爆破、Ed25519 |
| account | 账号 | 注册/注销/设备防刷赠分/密码重置 |
| points | 积分 | 预扣-确认-退还、离线对账、流水导出 |
| billing | 计费订阅 | 商品/下单/回调/退款/月赠 |
| entitlement | 权益内容 | 快照签发、内容库、manifest 增量 |
| notification | 通知 | 异步发送、验证码限流、续费提醒 |
| scheduler | 调度器 | 月赠/到期冻结/每日对账 |
| presence | 在线状态 | 心跳、在线判定、分钟趋势 |
| dashboard | 看板 | 指标查询、SSE 实时流 |
| reporting | 运营报表 | 积分分析（P3）/资产明细（P4）只读聚合 |
| monitoring | 运行监测 | 采样、告警、快照沉淀 |

### 2.2 集成关系矩阵（生产 → 消费）

| 生产方 | 消费方 | 集成点 | 机制 |
|---|---|---|---|
| account（注册） | points（赠分） | `points.registration_grant` 事件 | 注册事务内同步入账（幂等 exec_id） |
| billing（支付回调） | points（积分入账） | `grant_points`（积分包/月赠） | 订单 paid 后同步入账（幂等） |
| billing（订阅） | entitlement（快照） | `subscriptions` 状态聚合 | 快照签发时读订阅+积分 |
| billing（订阅） | notification（续费提醒） | `renewal_reminder` | 到期前 3 天提醒 |
| scheduler（月赠） | points（月度积分） | `grant_points`（monthly） | 幂等批次 + exec_id 年月 |
| scheduler（到期冻结） | points（冻结） | `set_frozen` | 订阅 expired → 账户冻结 |
| scheduler（对账） | points（流水） | `ledger_net` vs 余额 | 差异告警 |
| presence（心跳） | metrics（趋势） | `upsert_minute` | 分钟桶聚合 |
| points/billing（流水/订单） | dashboard（报表） | 聚合查询（日趋势/分布/商品销售） | 只读聚合，UTC 日、整数分 |
| presence/events | dashboard（SSE） | `presence.online_count` / `dashboard.events` | 版本化事件总线 |
| monitoring | dashboard（看板） | 运行监测整合 | 采样器 + 告警缓存 |

### 2.3 数据流闭环（DF 口径）

| 数据流 | 链路 | 状态 |
|---|---|---|
| DF-001 注册登录 | auth → account → 令牌 | ✅ |
| DF-003 订阅购买 | billing 下单 → 回调 → 积分/订阅入账 | ✅ |
| DF-004 阶段预扣 | points reserve → 许可签发 | ✅ |
| DF-007 确认退还 | points confirm/refund | ✅ |
| DF-005 离线对账 | points reconcile → 补扣/冻结 | ✅ |
| DF-008 月赠 | scheduler → points 月度积分 | ✅ |
