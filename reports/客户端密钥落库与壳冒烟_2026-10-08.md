## 1. 密钥密文落库（F1/F3 收尾关闭）

**驱动选型**：`node:sqlite`（Electron 37 内置 Node 22.21.1 实测可用）——**零原生依赖**，直接规避方案 §12 风险 3（better-sqlite3 与 Electron ABI 冲突/electron-rebuild）。

- 新增 [sqlite-secret-store.ts](file:///d:/shumoAgent/Edros/client/main/sqlite-secret-store.ts)：`SecretStore` 的 SQLite 实现；
  - 表结构 = `migrations.ts` v1 的 `secrets(scope, ciphertext)`（只存密文）；构造即执行迁移链（幂等）；
  - 一致性：`PRAGMA journal_mode=WAL` + `busy_timeout=5000`（架构约定）；
  - 删除语义：空密文 = 已删除（与 `KeyVault.remove` 一致，读侧归一为 null）；
  - 工厂 `createSqliteSecretStore` 在驱动/路径不可用时返回 null（调用方回退内存并告警，不静默降级）。
- 接线：[bridge.ts](file:///d:/shumoAgent/Edros/client/main/ipc/bridge.ts) 支持注入 `secretStore`（默认内存，向后兼容）；[index.ts](file:///d:/shumoAgent/Edros/client/main/index.ts) 实际注入 `userData/erdos.db`。
- 测试：`tests/sqlite-secret-store.test.ts` **9 例**（迁移就位/读写往返/**跨实例持久化**/删除语义/UPSERT/无重复行/WAL/迁移幂等/工厂降级）。

## 2. 壳级冒烟（FE-HOST W3 验收预演 / 10-24 前置）

无窗口、可无人值守自动化，覆盖既有单测覆盖不到的「Electron 主进程 + 真实引擎」链路：

- [smoke.ts](file:///d:/shumoAgent/Edros/client/main/smoke.ts)（主进程内冒烟跑手）：spawn 引擎（首行 Key 注入）→ initialize 握手 → task_create → 四阶段顺序推进（start_stage → 等 `stage.progress≥1` → `answer_gate(gate_<stage>, pass)`）→ `artifact.ready(paper)` → 优雅退出；
- [index.ts](file:///d:/shumoAgent/Edros/client/main/index.ts)：`ERDOS_SMOKE=1` 分支（不建窗口、不走单实例锁），退出码 0/1；
- [smoke-electron.mjs](file:///d:/shumoAgent/Edros/client/scripts/smoke-electron.mjs)：前置检查（构建产物/引擎环境）→ 启动 → 汇总步骤与退出码；`npm run test:smoke`。

**实测（本机 2026-10-08，FakeLLM 无 Key 模式）**：

|---|---|---|

事件统计：`stage.progress×8 + artifact.ready×1`；状态轨迹 `spawning → ready →（running → ready）×4 → stopped`（状态机与方案 §3.2 一致）。

## 3. 冒烟发现并修复的缺陷（关键）

**首次冒烟即暴露启动即崩级缺陷**：ESM 主进程包内嵌 CJS 依赖（electron-updater → fs-extra → graceful-fs）触发
`Error: Dynamic require of "fs" is not supported`（esbuild 的 `__require` 垫片在纯 ESM 产物中无 `require` 可委托）——**应用启动即崩，且单测/类型检查/产物扫描均无法发现**。

- 修复：构建改为 [build-main.mjs](file:///d:/shumoAgent/Edros/client/scripts/build-main.mjs)（esbuild JS API），注入
  `banner: import { createRequire } from "node:module"; const require = createRequire(import.meta.url);`
  （垫片委托真实 require；保留 ESM 语义与 `import.meta.url`）；构建逻辑同时收敛为可维护脚本（去内联引号地狱）。
- 该修复同时覆盖 `npm start` / 打包产物路径（此前构建产物启动即崩）。
